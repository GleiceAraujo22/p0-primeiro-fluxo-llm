## Sobre o projeto

Projeto desenvolvido como parte do Programa de Capacitação em Desenvolvimento de Agentes de IA.

O objetivo é identificar um problema real envolvendo interpretação ou geração de texto e desenvolver uma aplicação em Python que utilize um Large Language Model (LLM) por meio de uma API.

## Objetivos técnicos

- Desenvolvimento de aplicação em Python.
- Integração com API REST de um LLM.
- Versionamento com Git e GitHub.
- Tratamento de erros e proteção de credenciais.
- Organização de ambiente reproduzível.
- Testes e documentação técnica.

## Tecnologias

- Python
- Git e GitHub
- API de LLM
